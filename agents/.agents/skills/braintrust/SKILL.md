# Braintrust CLI (`bt`)

Hand-maintained. Originally generated by `bt setup skills` — do **not**
regenerate over this file; if upstream changes materially, re-trim by hand.
For command syntax, trust the installed binary over this file:
`bt --help`, `bt eval --help`, `bt sql --help`, `bt view --help`.

## Auth

- `bt auth status` to confirm; `bt auth login` (OAuth by default) to set up.
- Resolution order: `--profile` > `--api-key` / `BRAINTRUST_API_KEY` >
  `BRAINTRUST_PROFILE` > org-matched profile > single-profile auto-select.

## Non-obvious behavior (the reason this file exists)

- **`bt eval`**: auto-detects a JS runner (`tsx`, `vite-node`, `ts-node`).
  On ESM / top-level-await errors, retry with `--runner vite-node`.
  Smoke runs: `--first N` or `--sample N --sample-seed S` (summary is
  labeled non-final). Forward args to the eval file after `--`.
- **`bt sql`**: queries must `FROM` a Braintrust table function, e.g.
  `project_logs('<PROJECT_ID>')`. No joins, subqueries, unions, or window
  functions. Paginate with `OFFSET '<CURSOR_TOKEN>'`. Runs non-interactively
  when stdin isn't a TTY or a query argument is given.
- **`bt view logs|trace|span`**: `--object-ref project_logs:<project-id>`;
  trace rows are truncated by default (`bt view span` for full payload);
  add `-j/--json` when output feeds further parsing.

## Docs

Prefetched docs may exist at `.bt/skills/docs/README.md` (local) or
`~/.config/bt/skills/docs/README.md` (global); SQL reference under
`reference/sql.md`. Refresh with `bt docs fetch --refresh`. Online:
https://www.braintrust.dev/docs

Prefer `bt` commands over direct API calls.
